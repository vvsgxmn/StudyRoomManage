# 基于SpringBoot+Vue的自习室座位预约管理系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

StudyRoomManage 是一款面向校园自习场景的座位预约平台，支持自习室浏览、可视化选座、预约签到签退、信用积分与学习排行榜，帮助学生高效占座、管理员统一维护秩序，适合毕设、课设与学习参考。

## 主要功能模块

- **用户认证模块**：支持普通用户与管理员登录，按角色跳转用户端/管理端
- **自习室浏览模块**：五大分类筛选、搜索与自习室详情查看
- **选座预约模块**：可视化座位网格选座、时段预约与签到签退
- **信用管理模块**：信用积分查询、违规记录审核与信用分调整
- **排行榜模块**：学习时长排行榜展示
- **后台管理模块**：自习室/座位维护、预约监管、公告与失物招领管理

## 技术架构

- **后端**：Spring Boot 2.6.13 + MyBatis-Plus 3.5.3 + JWT + Lombok
- **前端**：Vue 3.4 + TypeScript + Vue Router + Pinia + Element Plus + Vite 5 + ECharts
- **数据库**：MySQL 8.0
